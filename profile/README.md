# BreadMod

![GitHub total stars](https://img.shields.io/github/stars/BreadMod?style=flat&logo=github&color=yellow&label=total%20stars)
![GitHub Repo Count](https://img.shields.io/badge/dynamic/json?url=https%3A%2F%2Fapi.github.com%2Forgs%2FBreadMod&query=%24.public_repos&logo=github&label=repo%20count&cacheSeconds=3600)

![Website Status](https://img.shields.io/website?url=https%3A%2F%2Fbreadmod.devstuf.dev&label=site%20status)


BreadMod is a Scratch mod that adds more customisability and blocks to Scratch. It is based on [TurboWarp](https://turbowarp.org/) but adds new features. Because of its core design, BreadMod can run Scratch projects but Scratch won't be able to run most BreadMod projects.
